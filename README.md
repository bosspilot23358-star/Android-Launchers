# Projector Home — лаунчер в стиле Apple TV для Umiio A007

Нативный Android-лаунчер без AndroidX и Gradle. Один Activity, никакого blur/теней-на-весь-экран/ресайклеров — всё сделано так, чтобы не тормозить на слабом SoC.

## Что умеет
- Большие часы и дата, горизонтальный ряд карточек 16:9, выбранная карточка увеличивается и «всплывает», ряд плавно центрируется на ней.
- Фон-подсветка плавно меняет цвет под цвет выбранного приложения.
- Берёт TV-баннеры у leanback-приложений (YouTube TV, Netflix и т.п.), для остальных рисует карточку из иконки.
- Сверху справа кнопки Wi-Fi / Bluetooth / Настройки (стрелка ↑ с ряда).
- Долгое нажатие OK (или кнопка Menu/Info): открыть, переместить влево/вправо, о приложении, удалить. Порядок запоминается.
- Кнопка Home возвращает на первую карточку. Мышь/аэромышь: клик по карточке запускает приложение.

## Сборка (без Gradle)
1. Нужен JDK 11+ и Android SDK с `build-tools` и `platforms` (любой android-30…35):
   ```
   sdkmanager --sdk_root=C:\android-sdk "build-tools;34.0.0" "platforms;android-34"
   ```
   (sdkmanager лежит в command-line tools с developer.android.com/studio; скачивание с Google — через VPN/зеркало.)
2. В папке проекта:
   ```
   java Build.java C:\android-sdk
   ```
   Получится `Launcher.apk` (подписан локальным `debug.keystore`; не удаляйте его — иначе обновление поверх не встанет).

## Установка на проектор
Через `adb install -r Launcher.apk` или с флешки через файловый менеджер. После установки нажмите Home — система предложит выбрать лаунчер, выберите «Projector Home» → «Всегда».
Если прошивка проектора жёстко привязана к своему лаунчеру, он останется доступным как обычное приложение, а Home можно переназначить в Настройки → Приложения → Приложения по умолчанию.

## Настройка вида
Все размеры в `MainActivity.java` считаются от размера экрана. Размер карточки — `cardW = W * 0.18f`, сила увеличения — `FOCUS_SCALE`.
