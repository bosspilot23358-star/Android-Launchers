# PlayHack5 1.1

Лаунчер и медиацентр для Android в стиле интерфейса PlayStation 5: тёмный фон, меняющий оттенок под цвет выбранной
игры, ряд плиток с увеличением выбранной, крупное название и кнопка «Играть». Вместо логотипа PS5 — PlayHack5.

* запускает установленные игры и приложения, может быть главным экраном (HOME);
* вкладка **Медиа**: видео, музыка, фото и обзор файлов (внутренняя память, USB/SD);
* встроенный проигрыватель на **libVLC** — открывает практически любые форматы видео и аудио;
* просмотр фото со слайдшоу и зумом;
* интерфейс рассчитан в том числе на экран **480×320** (например, 3.5" по HDMI от Raspberry Pi 3B).

## Управление (везде одинаковое)

| Действие | Геймпад | Клавиатура | Мышь / тач |
|---|---|---|---|
| Выбор | D-pad, левый стик | стрелки | колесо, клик |
| Подтвердить / запуск / пауза | ✕ (A) | Enter, Space | клик |
| Назад | ○ (B) | Esc | правая кнопка |
| Опции (добавить в «Игры», дорожки, слайдшоу) | △ (Y), □ (X), Start | Menu | долгое нажатие |
| Вкладки / предыдущий-следующий трек или фото | L1 / R1 | PgUp / PgDn, Tab | клик по вкладке |

**Главный экран:** ←/→ выбор плитки, ↑/↓ или L1/R1 — вкладки (Игры, Приложения, Медиа, Настройки).

**Видео и музыка:** ←/→ перемотка на 10 с (удерживайте — на 30 с), ↑/↓ громкость, ✕ пауза,
L1/R1 — предыдущий/следующий файл папки, △ — меню (звуковая дорожка, субтитры, формат кадра, скорость),
○ — выход. Мышь: клик по шкале внизу — перемотка, колесо — громкость, клик по экрану — пауза.
Субтитры рядом с файлом (.srt и др.) подхватываются автоматически. У музыки показываются обложка и теги.

**Фото:** ←/→ листать, ✕ или ↑ — приблизить (дальше стрелки двигают кадр), ○ — сброс зума/выход,
△ — слайдшоу (5 с). Мышь: колесо — зум, перетаскивание — сдвиг, клик по левой/правой трети — листать.

## Форматы

* **Видео/аудио:** всё, что умеет VLC (MKV, MP4, AVI, MOV, WMV, FLV, WebM, TS/M2TS, VOB, OGV, RMVB, MP3, FLAC,
  OGG/Opus, WAV, AAC/M4A, WMA, APE, AC3/DTS и т.д.). Аппаратное декодирование включено, при отсутствии — программное.
  Тяжёлые файлы (4K HEVC и т.п.) на слабой плате могут идти с пропусками кадров.
* **Фото:** JPG, PNG, WebP, BMP, GIF (первый кадр), HEIC/AVIF — в зависимости от версии Android на плате.
  Большие снимки уменьшаются при загрузке, чтобы не переполнять 2 ГБ ОЗУ.
* Музыка играет, пока открыт плеер; при выходе на главный экран остановится (фонового сервиса нет).

## Первый запуск медиа: доступ к файлам

Вкладка «Медиа» → «Видео»/«Музыка»/«Фото»/«Файлы». Если доступа ещё нет, первой строкой будет
«Разрешить доступ к файлам» — откроется системная страница, включите переключатель для PlayHack5 и вернитесь.
Если на вашем образе Android такой страницы нет, выдайте доступ с компьютера:
```
adb shell appops set com.playhack5 MANAGE_EXTERNAL_STORAGE allow
adb shell pm grant com.playhack5 android.permission.READ_EXTERNAL_STORAGE
```
USB-флешки видны как «USB / SD: <имя>».

## Оптимизация под слабые платы (Radxa ROCK 2F 2 ГБ, Raspberry Pi 3B)

* Интерфейс — лёгкие самодельные View: без теней, размытия и вложенных слоёв.
* Иконки грузятся в фоне, кэш 8–14 МБ, иконки не больше 256×256.
* **Лёгкий режим** включается автоматически при ≤3 ГБ ОЗУ: отключает анимации. Переключатель — «Настройки».
* Размеры интерфейса считаются от высоты экрана; на экранах высотой ≤420 px (480×320) используются только
  относительные размеры, всё помещается без прокрутки. Список файлов и меню на таком экране показывают 5–7 строк.
* В APK только ARM-библиотеки (arm64-v8a, armeabi-v7a).

## Сборка APK

Размер APK около 40–60 МБ — из-за libVLC.

### 1. Без Android Studio и Gradle (рекомендуется)

Нужен **только JDK 17** (например Temurin: https://adoptium.net — при установке включите «Add to PATH»).
Gradle, Android Studio и GitHub не нужны. Распакуйте проект в папку с обычным путём без кириллицы
(например `C:\PlayHack5`) и запустите:

```
build.bat            (Windows: двойной щелчок)
./build.sh           (Linux / macOS)
java Build.java      (то же самое вручную, из папки проекта)
```

При первом запуске скрипт сам скачает:

| Что | Откуда | Размер |
|---|---|---|
| Android command-line tools | dl.google.com | ~150 МБ вместе с SDK |
| платформа android-34 и build-tools 34.0.0 | через sdkmanager (dl.google.com) | |
| libVLC 3.6.2 (`.aar`) | Maven Central, при недоступности — зеркала Aliyun и Huawei | ~70 МБ |

Дальше всё делается локально за 1–2 минуты: aapt2 → javac → d8 → упаковка → zipalign → подпись.
Готовый файл — `PlayHack5.apk` в папке проекта. Подписан стандартным debug-ключом
(`~/.android/debug.keystore`, создаётся сам), поэтому обновление поверх предыдущей версии работает.

Команды:

```
build.bat setup                  только скачать SDK
build.bat install                поставить APK через adb (USB)
build.bat install 192.168.1.50   поставить по сети (adb connect), плюс сразу выдаёт доступ к файлам
build.bat clean                  удалить папку build
build.bat --abi=all              включить x86/x86_64 (по умолчанию только ARM: arm64-v8a, armeabi-v7a)
```

**Если скачивание не идёт** (сайты Google недоступны без VPN):

* включите VPN и запустите ещё раз — недокачанное скачается заново;
* либо скачайте файлы в браузере и положите в папку `libs/` — скрипт найдёт их сам
  (ссылки в `libs/README.txt`): `libvlc-all-3.6.2.aar` и `commandlinetools-win-11076708_latest.zip`;
* либо возьмите готовый Android SDK с другого компьютера/из Android Studio: нужны папки
  `platforms/android-34` (подойдёт любая от 30) и `build-tools/34.0.0` (подойдёт любая).
  Положите их в `sdk/` внутри проекта или укажите `--sdk=ПУТЬ`, либо переменной `ANDROID_HOME`;
* прокси: `set PH_SDK_PROXY=127.0.0.1:10809` (для sdkmanager) и
  `set JAVA_TOOL_OPTIONS=-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=10809` (для скачивания libVLC);
* свой Maven-репозиторий/зеркало: `set PH_MAVEN=https://my.mirror/maven2`.

Этот способ собирает без R8-сжатия: на размер это почти не влияет (почти всё — libVLC), работе не мешает.
Сборка рассчитана на обычный ПК (Windows/Linux x86-64): утилиты Android SDK (aapt2, zipalign) под ARM-Linux
не выпускаются.

### 2. Android Studio
File → Open → папка `PlayHack5` → дождаться синхронизации Gradle → Build → Build APK(s).

### 3. Командная строка Gradle
Нужны JDK 17, Android SDK (platform 34), Gradle 8.9+ и доступ в интернет:
```
gradle assembleRelease
```
Результат: `app/build/outputs/apk/release/app-release.apk` (с R8, подписан debug-ключом).

### 4. GitHub Actions
Загрузите папку в свой репозиторий → вкладка Actions → «Build APK» → Run workflow → скачайте артефакт `PlayHack5-apk`.

## Установка на плату

Нужен образ Android 5.0+.
```
adb connect <IP-платы>:5555
adb install -r PlayHack5.apk
```
Чтобы PlayHack5 запускался сразу после включения: «Настройки» → «Главный экран» → PlayHack5 → «Всегда».

## Структура кода

`Build.java` — сборка APK без Gradle; `MainActivity` — главный экран; `BrowserActivity` — файлы; `PlayerActivity` — видео/аудио (libVLC);
`ImageActivity` — фото; `Keys` — единая раскладка клавиатуры/геймпада; `Ui` — размеры; `ListPanel` — меню выбора;
`Views`, `Hints`, `Glyphs` — отрисовка; `IconCache`, `Store`, `MediaUtil` — данные.
